# Answer-quality evaluation (EVAL-03)

Generated by `node scripts/eval-quality.mjs` on 2026-11-24. Raw per-run data: `scripts/out/eval-quality.json` (not committed; regenerate with the command).

## What was measured

The same 5 tasks on the synthetic sample contract (16 clauses, 3031 characters, all values invented) were answered by real cloud Gemini (`gemini-3.5-flash-lite` through Firebase AI Logic, free tier, the model the app uses) under four arms, 3 repeats per task and arm.

| Arm | What leaves the machine |
|---|---|
| A. Baseline | The full document and the task, unprotected. This is the no-AIRLOCK control. |
| B. AIRLOCK | The real pipeline: on-device Gemini Nano (`ONLY_ON_DEVICE`) picks the passages the task needs, deterministic policy masks sensitive values, the payload is approved, sent, and the answer is restored. The harness plays the approver through the same store call the Approve button makes. |
| C1. Withhold | A gateway that sends the task and nothing from the document. A metric that rewarded this would be broken. |
| C2. Over-mask | A gateway that sends the full document with every number replaced by `[NUM]`. Safe-looking, but it destroys the facts the tasks need. |

Scoring is deterministic: each task lists expected facts as normalized (lowercased, markdown stripped, whitespace collapsed) regular expressions, checked against the answer **after** AIRLOCK restores placeholders. There is no LLM judge. A run succeeds only if **every** expected fact is present; fact recall is the share present. The expected facts are listed in `scripts/eval-quality.mjs`.

The first attempt hit a Firebase AI Logic cloud outage (HTTP 500 "high demand", which also persisted through retries); 5 failed runs were redone after the cloud recovered, and their wasted calls are included in the call count below.

The first task wording ("Is the non-compete and non-solicitation wording reasonable, and what would I ask to change?") returned HTTP 500 ("high demand") from the cloud model in all four arms over 12 calls, and again 58 s into a later manual retry, while shorter prompts succeeded in the same minutes. It was replaced by the factual wording in the report so the arm comparison is not dominated by an outage on one prompt.

Environment: Chrome/158.0.8127.37, on-device model Gemini Nano via the Prompt API, 79 cloud generateContent calls counted on the wire (CDP Network log; this includes calls that failed with HTTP 500 and were redone), budget 80, plus 5 manual diagnostic calls made outside the harness count.
